Open the first-run setup guide in one window instead of one per window, the last optional extension of the multi-window polling lease design. The guide used to be arbitrated by a flag in the editor's global state, which is read-then-written and therefore not atomic between windows: windows restored together on a fresh install could each open the panel. Windows activating at the same moment now coordinate through a short-lived offer token in the profile's globalStorage (`first-run-guide-offer.json`, created with an exclusive `fs.open(…, 'wx')` and mode `0600`, the lease's own primitive): the window that creates it opens the guide, and the others stay silent while that offer is plausible — the offering window is still running and the token is fresh. The token is not a "shown forever" record: once its owner is gone, or the offer has expired, the next activation takes it over and offers the guide again, so a profile with no configured instance keeps being nudged until an instance is added or the guide is completed, exactly as before. What makes the guide permanent is still the `forgejoToolkit.hasShownWelcome` flag, written when the guide is completed or when an instance exists. The failure direction is the safe one in both cases: if the token cannot be created (a read-only profile directory, a denied create), that window opens the guide rather than staying silent, and a token it cannot clean up makes it stay silent rather than open a second panel.
