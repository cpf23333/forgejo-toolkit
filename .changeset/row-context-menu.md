**Row actions where the row is.** Right-clicking a repository, pull-request, issue or notification row
in the sidebar now shows the actions that belong to that row — open the repository, pull request or
issue, copy its address or number, open it in the browser, mark a notification as read — contributed as
VS Code-native menu items. The editor's cut/copy/paste menu no longer appears on those rows, where it
had nothing to act on; fields and selected text keep it, as before.
