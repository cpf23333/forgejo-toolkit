Add the AI pre-review: a `forgejoToolkit.aiPreReviewPullRequest` action in the pull request diff editor that asks a chat model (through `vscode.lm` on the host) for line-level review comments and turns only the ones you confirm into drafts of a pending review. It never submits a review, nothing is written unconfirmed, and the confirmation list starts with nothing selected. Off by default through the new `forgejoToolkit.aiPreReview` setting; with it off the command refuses without sending anything. By default the model receives the pull request metadata, the changed-file paths with their line counts, and the metadata of existing review comments — the changed lines of code (the diff body) are sent only when the second window-scoped setting, `forgejoToolkit.aiPreReviewIncludeDiff`, is on as well. Anchors are validated against the diff's real lines and dropped — never moved, flipped or clamped — when they do not fit. The run shows cancellable progress while it reads and asks, and the model it uses is the offered one whose input budget can take the request rather than the first one listed; when no offered model can hold even the instructions, the message names how many there were and the largest input budget among them. When a model's answer is not the JSON the feature asks for, the run asks the next affordable model instead of stopping — at most three models per run, each asked once — and starts from a model whose answers satisfied that contract earlier in the same window when there is one; only a contract failure is retried, and if every attempt fails the message names each model and how its answer fell short (an empty answer, an answer that is not JSON, or JSON whose shape is wrong, naming the field). The log names the model by vendor, family and id, and describes the answer only by a bounded shape — never the answer, the brief or the diff.
