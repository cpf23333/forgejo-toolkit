## [0.0.1] - 2026-07-31

### Added

- Initial release of Forgejo Toolkit.
- Multi-instance management for Forgejo/Codeberg servers.
- Dashboard panel showing repositories, Issues, and Pull Requests grouped by instance.
- Repository detail view with README preview, recent commits, refs, and file browser.
- File browser with directory tree, file search, single-file history, and diff viewer.
- Issue / PR list, detail, create, edit, close/reopen, and Markdown rendering.
- PR diff support using VS Code's native diff editor.
- PR worktree checkout from the detail page.
- Internationalization support for Chinese and English.
- Debug logging toggle for API requests.
